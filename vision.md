*"the web needs to be more patient with humans"*

I would like to imagine a new browser, because I feel that is the best way to imagine working on a problem. Sometimes, problems become small in the context of the existing environment, at that point, I think you have to start competing with the environment itself.

My thoughts about the current web and browsers is:
1. One wrong click and the tab that wasn't meant to be closed closes.
2. So much on the web is organized by service providers, I want more control over it. So a smaller layer of organization of the web, should be possible. I already do this a lot and am happy with it. But it could be better.
3. I want the browser to be more OS like or the OS to be more browser like

The one thing I am happy about the web is the ability it has to save my interactions and state where I leave it after every "activity period", and it is only because of that being present, am I asking for more. So, I already have a good experience. And I am not saying it is not commendable what has been achieved.
